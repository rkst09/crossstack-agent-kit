# Code of Conduct

Participants in this project are expected to be respectful, constructive, and professional. Focus criticism on ideas and code, assume good intent where reasonable, and welcome contributors with different experience levels.

Unacceptable behavior includes harassment, discrimination, personal attacks, doxxing, deliberate sharing of private information, or persistent disruptive conduct.

Project maintainers may edit, reject, or remove contributions that violate this standard. Report concerns privately to the repository owner or through the hosting platform's reporting tools.
