# Roadmap

## v1 scope (included)

- Six focused Agent Skills.
- Python-standard-library installer with host path selection and overwrite protection.
- Structural validator and tests for repository tooling.
- Twenty-four synthetic scenario definitions.
- Working .NET + React/TypeScript nullable-field example.
- CI for repository checks, frontend type-check/tests/build, and backend build.
- Installation, evaluation, security, contribution, and release-gate documentation.

## Future improvements — require evidence before expanding

1. Add a versioned sample demonstrating a cross-layer `403 Forbidden` / frontend error-state contract.
2. Add an opt-in evaluation runner only when the project can define a clear model/host adapter and stable reporting format without hidden API costs.
3. Add Power Fx linting or formula checks only if they can be backed by reproducible inputs and maintained rules; do not imply that a text-only validator can certify delegation.
4. Track host-specific activation compatibility with recorded versions and reproductions.
5. Add focused skills only when they solve a distinct recurring problem and do not duplicate official repositories.

A larger skill count is not a roadmap goal by itself. Prefer fewer skills with clear outcomes and maintained references.
